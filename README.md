# 하루 2.2.2 — 화면 배치 및 아이콘 개선

- 상단 글씨 확대 및 굵기 강화
- 일정 추가·할 일 추가 버튼이 카드 내부에서 겹치지 않도록 배치
- 작은 화면에서는 내용 영역만 스크롤하도록 유지
- 사용자가 제공한 아이콘을 192px/512px로 적용
- 일정·할 일 저장 키와 기존 기능 유지
- 서비스워커 캐시 버전 갱신

## 배포
ZIP을 압축 해제한 후 내부 파일들을 기존 GitHub 저장소의 동일한 위치에 업로드하세요. 기존 파일을 교체하되 GitHub Pages 주소는 유지하세요. 기존 데이터는 브라우저 로컬 저장소에 있으므로 업데이트 전에 앱 설정에서 JSON 백업을 권장합니다. 홈 화면 아이콘은 iOS 캐시로 인해 바로 바뀌지 않을 수 있습니다.

## 주의
실제 iPhone 화면에서의 최종 동작은 배포 후 확인이 필요합니다. 앱이 종료된 상태의 iOS 푸시 알림은 아직 구현되지 않았습니다.

## 2.2.3 버튼 위치 수정
- 일정 추가·할 일 추가 버튼을 카드 내부 마지막 행에 고정하여 테두리와 겹치지 않도록 변경
- 기존 저장 키와 일정·음력·음성 기능 유지
- 서비스워커 캐시 이름 갱신
