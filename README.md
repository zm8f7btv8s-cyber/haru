# 하루 2.0 — 프리미엄 세이지 & 아이보리 개인 일정 비서

하루 2.0은 기존 개인용 PWA를 바탕으로 홈 화면 아이콘과 앱 화면을 프리미엄 세이지 & 아이보리 스타일로 정리한 버전입니다. 일정과 할 일은 기존처럼 현재 브라우저의 `localStorage`에 저장되며, 일정 데이터 구조와 백업 형식은 유지합니다.

## 기존 기능 및 1.3 기반
- 기존 홈 화면 아이콘 파일과 연결 구조 유지 (아이콘 교체는 별도 확인 필요)
- 앱 화면의 포레스트 그린·세이지·아이보리 계열을 통일하고 카드, 달력, 입력창, 하단 메뉴를 정돈
- 아이폰 화면 안전 영역과 하단 고정 액션 버튼 유지
- 일정 입력창 글자 크기 16px 이상으로 유지해 Safari 자동 확대를 방지
- 월간 달력에 음력 날짜와 주요 음력 기념일·공휴일 표시, 휴일/토요일 색상 구분
- 기존 일정·할 일 저장 키와 JSON 백업 구조 유지
- 서비스워커 캐시 버전 갱신

## 파일
- `index.html`: 앱 화면 구조
- `styles.css`: 반응형 프리미엄 세이지 & 아이보리 디자인
- `app.js`: 일정, 할 일, 캘린더 및 저장 기능
- `lunar-data.js`: 오프라인 음력 변환 데이터
- `manifest.webmanifest`: 홈 화면 앱 설정 및 아이콘 연결
- `icon-192.png`, `icon-512.png`: 홈 화면 아이콘
- `sw.js`: 오프라인 캐시

## 배포
기존 GitHub 저장소의 앱 파일을 이번 압축파일의 파일로 교체해 업로드하세요. ZIP 파일 자체를 저장소에 추가하는 것이 아니라 압축을 풀어 `index.html`, `styles.css` 등 11개 파일을 저장소의 기존 위치에 반영해야 합니다. 기존 GitHub Pages 주소와 저장소 설정은 유지하세요. 업로드 후 Pages 배포가 완료되면 기존 주소를 Safari에서 새로고침해 확인하세요. 홈 화면 아이콘은 캐시 때문에 바로 바뀌지 않을 수 있으며, 이번 버전에서는 아이콘 이미지 자체를 교체하지 않았습니다.

## 데이터 주의
일정과 할 일은 기기·브라우저별 로컬 저장소에 저장됩니다. 배포 전후에 기존 데이터가 유지되는지 확인하고, 업데이트 전 JSON 백업을 권장합니다. 서버 동기화는 포함하지 않습니다.

## 알림 한계
전날 19시·당일 09시·일정 1시간 전 알림 설정은 앱에 저장되지만, 웹앱이 닫힌 상태에서 iOS 알림이 실제로 전송되는 기능은 포함하지 않습니다. 이를 보장하려면 네이티브 iOS 앱 또는 별도 푸시 인프라가 필요합니다.


## 2.0 디자인 개선
- 딥그린 일변도에서 포레스트 그린 헤더 + 웜 아이보리 배경으로 밝기 균형 개선
- 캘린더를 밝은 세이지 톤으로 변경하고 토요일 블루·일요일/공휴일 테라코타 대비 강화
- 일정/할 일 카드, 입력창, 모달, 하단 메뉴를 라이트 테마로 통일
- 서비스워커 캐시 버전을 갱신해 새 CSS가 다시 내려오도록 변경
