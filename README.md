# 하루 1.3 — 모던 포레스트 개인 일정 비서

하루 1.3은 기존 개인용 PWA를 바탕으로 홈 화면 아이콘과 앱 화면을 모던 포레스트 스타일로 정리한 버전입니다. 일정과 할 일은 기존처럼 현재 브라우저의 `localStorage`에 저장되며, 일정 데이터 구조와 백업 형식은 유지합니다.

## 1.3 변경 사항
- 아이폰 홈 화면용 하루 아이콘을 새 모던 포레스트 디자인으로 교체
- 앱 화면의 포레스트 그린·세이지·아이보리 계열을 통일하고 카드, 달력, 입력창, 하단 메뉴를 정돈
- 아이폰 화면 안전 영역과 하단 고정 액션 버튼 유지
- 일정 입력창 글자 크기 16px 이상으로 유지해 Safari 자동 확대를 방지
- 월간 달력에 음력 날짜와 주요 음력 기념일·공휴일 표시, 휴일/토요일 색상 구분
- 기존 일정·할 일 저장 키와 JSON 백업 구조 유지
- 서비스워커 캐시 버전 갱신

## 파일
- `index.html`: 앱 화면 구조
- `styles.css`: 반응형 모던 포레스트 디자인
- `app.js`: 일정, 할 일, 캘린더 및 저장 기능
- `lunar-data.js`: 오프라인 음력 변환 데이터
- `manifest.webmanifest`: 홈 화면 앱 설정 및 아이콘 연결
- `icon-192.png`, `icon-512.png`: 홈 화면 아이콘
- `sw.js`: 오프라인 캐시

## 배포
압축을 풀고 모든 파일을 기존 Cloudflare Pages 프로젝트에 새 배포로 업로드하면 됩니다. 기존 프로젝트 주소를 유지하면 홈 화면 바로가기 주소도 그대로 사용할 수 있습니다. 업데이트 후 아이콘이 바로 바뀌지 않으면 홈 화면 바로가기를 삭제한 뒤 Safari에서 사이트를 다시 열어 홈 화면에 추가하세요.

## 데이터 주의
일정과 할 일은 기기·브라우저별 로컬 저장소에 저장됩니다. 배포 전후에 기존 데이터가 유지되는지 확인하고, 업데이트 전 JSON 백업을 권장합니다. 서버 동기화는 포함하지 않습니다.
